## 1. 先弄清几个概念

| 概念 | 说明 |
|---|---|
| **项目 = 文件夹** | 在哪个文件夹启动 `agent chat`，那里就是这次的**产物目录**，剧本、图片、视频、成片都存在那里；会话、资产、记忆、单项目预算也按这个文件夹归档。Agent 自己的状态（资产库、台账、记忆、日志）放在仓库的 `workspace/` 里，不跟着项目文件夹走。 |
| **产线** | 短剧 / 抖音短视频 / 广告 / 设计。决定模型能看到哪些方法论、优先用哪些工具、默认锁定哪个生成模型。用 `/type` 切换。 |
| **工具与 skill** | 工具（function）回答「能做什么」，共 40 多个，`/tools` 可以查看；skill 回答「怎么做好」，是 `skills/` 下的方法论 markdown，模型按需加载，改完存盘就生效。 |
| **资产** | 所有产出（剧本、分镜、图片、视频……）都存成带 id（形如 `as_xxxxxxxxxx`）、带版本和血缘的资产。改写挂在原版下面，不会覆盖原版。 |
| **人审** | 模型请你拍板：`a` 采纳 / `r` 打回重写 / `j` 方向不对退回。大节点（剧本、视频生成、图片生成、换模型等）始终会问你；小节点（单集）在 `/auto` 下自动采纳。 |
| **确认** | 权限闸门弹出 `执行吗？(y/N)`：不可逆或对外的操作、写到产物目录以外、超出额度、整批报价时都会出现。 |
| **额度与报价** | 每次开工先确认一次额度；渲参考图、渲每一集、定音之前各报一次价，你回 `y` 才开始花钱。 |
| **权限等级** | `L-read` 只读 · `L-write` 改本地、可回滚 · `L-compute` 花钱或产出资产（额度内自动放行）· `L-external` 不可逆或对外（每次都问）。 |

## 2. 安装

### 2.1 准备

| 依赖 | 用途 | 是否必需 |
|---|---|---|
| Python 3.11+ | 运行（代码用到了 3.11 才有的 `StrEnum`、`TaskGroup`；作者用 3.11.9 实测） | 必需 |
| ffmpeg + ffprobe（在 PATH 上） | 拼接成片、配音混音、字幕、叠字、抽帧、短剧质检门 | 出视频必需 |
| Git | 克隆仓库 | 必需 |
| Chrome 或 Edge | 浏览器采集（RPA）、爆款拆解导出 PDF | 可选 |
| 中文字体 | 海报叠字、视频叠字（Windows 自带微软雅黑） | macOS / Linux 需要自己装 CJK 字体 |

安装 ffmpeg：

```bash
winget install Gyan.FFmpeg        # Windows（或 choco install ffmpeg），装完重开终端
brew install ffmpeg               # macOS
sudo apt install ffmpeg           # Ubuntu / Debian
ffmpeg -version                   # 验证
```

ffmpeg 需要带 libx264、aac、libmp3lame 和 libass（`subtitles` 滤镜），常见的完整构建都带。

### 2.2 安装步骤

**Windows（PowerShell）**

```powershell
git clone https://github.com/yihuandeps/aigc-agent.git
cd aigc-agent
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -e ".[p1]" -c requirements-lock.txt
```

**macOS / Linux**

```bash
git clone https://github.com/yihuandeps/aigc-agent.git
cd aigc-agent
python3.11 -m venv .venv
.venv/bin/python -m pip install -e ".[p1]" -c requirements-lock.txt
```

- `requirements-lock.txt` 是作者实测可用的版本组合（全量测试通过），作为**约束文件**使用：只锁版本，不会多装没用到的包。
- 必须从源码目录以 editable 方式（`-e`）安装运行：`.env`、`config/`、`skills/`、`workspace/` 都按仓库位置查找，打成普通 wheel 安装会找不到它们。
- `.venv` 要放在仓库根目录（Windows 的 `agent.cmd` 靠相对位置找它）。

可选依赖组（多个组用逗号连起来，比如 `".[p1,rpa,douyin]"`）：

| 组 | 内容 | 什么时候装 |
|---|---|---|
| `p1` | `mcp`（2.x） | 推荐：自带的本地素材库 MCP server 要用 |
| `rpa` | `playwright` | 用浏览器采集（小红书搜索、抖音热榜 RPA）时。优先用系统里的 Chrome / Edge，没有的话再 `python -m playwright install chromium` |
| `douyin` | `markdown`、`yt-dlp` | 爆款拆解：报告导出 PDF 要用 `markdown`；没有 TikHub 时用 `yt-dlp` 下载抖音视频（还需要你导出的 cookies） |
| `dev` | pytest、pytest-asyncio、ruff、import-linter | 跑测试和 lint 时 |

例如要用全部功能：`pip install -e ".[p1,rpa,douyin]" -c requirements-lock.txt`。

### 2.3 让 `agent` 命令在任意文件夹可用

因为「项目 = 文件夹」，你会经常在别的文件夹里运行 `agent`。三种方式任选：

- **Windows**：把仓库根目录加进 PATH，直接用仓库根目录的 `agent.cmd`（不用激活虚拟环境；它会自动设置 UTF-8 输出）。
- **激活虚拟环境**：`.venv\Scripts\activate`（Windows）或 `source .venv/bin/activate`（macOS / Linux），之后直接用 `agent`。
- **写全路径**：`<仓库>\.venv\Scripts\agent.exe` 或 `<仓库>/.venv/bin/agent`。

### 2.4 Windows + 中文路径

仓库放在含中文的路径下（例如 `E:\手搓Agent`）时，Python 3.11 读取 editable 安装生成的 `.pth` 文件会按系统编码（cp936）解码，导致 `import aigc_agent` 失败。

- 最简单的办法：**把仓库放在纯英文路径下**。
- 非要用中文路径的话，把 `.venv\Lib\site-packages\_editable_impl_aigc_agent.pth` 的内容改成下面这一行（注意：重新执行 `pip install -e .` 会把它覆盖掉，需要再改一次）：

```
import os,sys; sys.path.insert(0, os.path.join(os.path.dirname(sys.prefix), 'src'))
```

你的**项目文件夹**用中文名没有问题，这个问题只和仓库本身的路径有关。

### 2.5 macOS / Linux 注意事项

作者只在 Windows 11 上实测过，macOS / Linux 理论上可以运行（会话锁、文件锁、打开文件都有跨平台实现），以下几点需要注意：

- 没有 `agent.cmd`，用 `.venv/bin/agent`。
- 浏览器采集必须有图形界面（小红书在无头模式下会返回安全限制页）；系统浏览器只识别 Windows 安装路径和 PATH 上的 `chrome` / `msedge`，通常需要 `python -m playwright install chromium`。
- 爆款拆解导出 PDF 在 Linux 上找不到浏览器路径，目前用不了。
- 海报找不到中文字体时用环境变量 `AIGC_POSTER_FONT` 指定字体文件；视频叠字写死了「Microsoft YaHei」，需要系统装有 CJK 字体，由 libass 自动替代。
- `config/filesystem.yaml` 里的 `E:/`、`C:/…` 等 Windows 路径要按自己的机器修改（见 3.5）。

## 3. 配置

> 配置文件只在启动时读一次，改完要重启 `agent`；`skills/` 下的方法论文档例外，存盘即生效。

### 3.1 密钥与环境变量（`.env`）

- `.env` 放在**仓库根目录**（不是项目文件夹），运行 `agent setup --write` 会从 `.env.example` 生成一份。
- 写法：每行 `KEY=值`。**不要在值后面写注释**（`#` 后面的内容会被当成值的一部分）；不支持 `export` 前缀；进程里已有的同名环境变量优先，`.env` 不会覆盖它。
- `.env` 已在 `.gitignore` 里。**真实 key 只写在 `.env`**，不要写进任何会提交的文件。

| 变量 | 用途 | 什么时候需要 | 服务 |
|---|---|---|---|
| `KIMI_API_KEY` | 主 Agent 和大部分文本角色：对话、写作子代理、记忆、机审、看图质检、抖音简报、选音色、分镜等 | **必需** | Kimi Code（`api.kimi.com/coding/v1`，订阅额度制；key 形如 `sk-kimi-…`，和 platform.moonshot.cn 的 key 不通用）；申请：https://www.kimi.com/code/console |
| `APIMART_API_KEY` | 生图、生视频、语音转写；短剧拆解与写剧本用的 gemini（`drama` / `drama_prose` 角色） | 短剧、短视频必需 | APIMart 聚合网关（`api.apimart.ai`）；申请：https://apimart.ai |
| `MINIMAX_API_KEY` | 中文 TTS 配音（默认 `speech-2.8-hd`） | 短视频需要口播时；短剧不需要（声音由 seedance 原生生成） | MiniMax（国内站，`api.minimax.cn`） |
| `MINIMAX_GROUP_ID` | 只有老式 MiniMax key 才需要 | 新式 `sk-api-` key 保留空值一行 `MINIMAX_GROUP_ID=`，**不要删掉这一行** | 同上 |
| `SEE_API_TOKEN` | 默认图床 S.EE：本地图片当参考图、过期的参考图重新上传 | 用本地照片当参考图时（见 3.4） | S.EE（`s.ee`） |
| `IMGBB_API_KEY` | imgbb 图床 | `hosting.yaml` 选 imgbb 时 | imgbb.com |
| `S3_ACCESS_KEY` / `S3_SECRET_KEY` | 对象存储托管 | `hosting.yaml` 选 s3 时 | 阿里云 OSS / 腾讯云 COS / Cloudflare R2 / MinIO / AWS S3 |
| `TIKHUB_API_KEY` | 抖音热榜与搜索；爆款拆解的公开数据、评论和无水印视频 | 可选。没有时热榜降级（流程照常继续），拆解只能处理本地视频 | TikHub（`api.tikhub.io`）；申请：https://tikhub.io |
| `DY_COOKIES` | 没有 TikHub 时，yt-dlp 下载抖音视频用的 cookies.txt 路径 | 可选 | — |
| `PEXELS_API_KEY` / `PIXABAY_API_KEY` | 联网找可商用素材（抖音、广告线缺实拍素材时） | 可选，配一个就够 | pexels.com/api、pixabay.com/api/docs |
| `HTTPS_PROXY` / `HTTP_PROXY` / `NO_PROXY` | 代理 | 看网络情况（见 3.3） | — |
| `AIGC_WORKSPACE` | 把运行时目录 `workspace/` 挪到别处 | 可选 | — |
| `AIGC_POSTER_FONT` | 海报叠字用的中文字体文件路径 | 可选 | — |

### 3.2 不同用途最少要配什么

| 用途 | 必需 | 建议 | 外部依赖 |
|---|---|---|---|
| 聊天、写文案、看图 | `KIMI_API_KEY` | 代理（看网络） | 无 |
| 短剧出片 | `KIMI_API_KEY` + `APIMART_API_KEY` | `SEE_API_TOKEN`（或其他托管方式）：本地照片当参考图、参考图链接过期后重新上传都要用 | ffmpeg / ffprobe |
| 抖音短视频 | `KIMI_API_KEY` + `APIMART_API_KEY` + `MINIMAX_API_KEY`（或把 TTS 换成 apimart） | `TIKHUB_API_KEY`（热榜）、Pexels / Pixabay（联网找素材）、playwright（浏览器采集） | ffmpeg / ffprobe |

APIMart 账户需要有余额，余额不足时接口会先返回 500、再返回 402。Agent 认得出这种情况：不再重试、不换模型，这一批后面的不再发，告诉你去充值；已经做好的部分都留着，充值后原样再跑一次只补没做的。Kimi Code 订阅额度窗口用完时同理，会提示你等窗口恢复。

### 3.3 代理

- 国内访问部分外部接口需要代理。在 `.env` 里配 `HTTPS_PROXY` / `HTTP_PROXY`。
- 设了代理之后，所有出站请求（包括国内端点）都走代理。
- `.env` 和环境变量里都没有代理时，会尝试借用 Claude Code 设置（`~/.claude/settings.json` 的 `env` 段）里的代理。
- 代理不通时，报错经常**伪装成「key 无效」**，先排查代理。

### 3.4 本地素材托管（`config/hosting.yaml`）

为什么需要：生成接口只接受公网 http(s) 链接（本地路径和 base64 在提交前就会被拒），而生成结果自带的链接大约 24 小时就会失效。用你自己的照片当参考图、过期的参考图重新上传，都要先把本地文件变成公网链接。

| `type` | 适合 | 需要 |
|---|---|---|
| `imghost` + `preset: see`（**默认**） | 没有对象存储 | `SEE_API_TOKEN` |
| `imghost` + `preset: imgbb` | 没有对象存储 | `IMGBB_API_KEY` |
| `imghost` + `preset: catbox` / `litterbox` | 不想注册（图片公开；litterbox 72 小时自动删除，过期前会自动重传；国内可能访问不了） | 无 |
| `s3` | 有阿里云 OSS / 腾讯云 COS / Cloudflare R2 / MinIO | `S3_ACCESS_KEY` / `S3_SECRET_KEY`，并填好 `endpoint`、`region`、`bucket` 等 |
| `command` | 已经有上传命令（ossutil、coscli、picgo……） | 命令输出的最后一行是链接 |
| `http_put` | 自建文件服务 | `auth_header` 只能写明文、会跟着配置文件进版本库，**别提交真实值** |
| `none` | 不托管 | 本地素材只能拼进成片，不能当参考图 |

在对话里可以让 Agent 调 `hosting_status` 查看当前托管是否可用。

### 3.5 文件访问范围（`config/filesystem.yaml`）

Agent 的本地文件工具（`fs_*`）只能访问：仓库目录、`workspace/`、当前产物目录，以及 `roots` 白名单。

- **仓库里的默认 `roots` 是作者机器上的 `"~"` 和 `"E:/"`，请改成你自己的素材盘或目录。**
- `material_dirs`：要自动索引的素材文件夹，加进去之后 Agent 能「看见」你已有的素材（单个目录最多索引 4000 个文件）。
- `deny` 只能往上加。`.env`、`*.pem`、`*.key`、`.ssh`、浏览器数据、RPA 登录态等由代码硬性拒绝，配置也删不掉这些规则。

### 3.6 模型（`config/models.yaml`、`config/media_models.yaml`）

- **文本**：`kimi_k3`（`k3-256k`）负责 16 个角色；`gemini`（`gemini-3.8-flash`，经 APIMart）负责 `drama` / `drama_prose` 两个角色（拆分镜、资产库、视频提示词、写剧本、扩写）。改 `text.roles` 可以换映射；改之前用 `agent models`、`agent models --role drama` 核对服务端实际可用的模型 id。
- **生图 / 生视频**：按档位（`fast` / `balanced` / `quality`）选默认模型；短剧固定用 `drama.image_model`（`gpt-image-2`）和 `drama.video_model`（`seedance-2.0`）。换生图模型前先确认新模型支持参考图。
- **TTS**：`audio.tts_provider: minimax`；没有 MiniMax 可以改成 `apimart`（中文口播会偏「假」）。查看可用音色：`agent story voices`。
- **质检门**：`drama` 段的 `realism_gate` / `subtitle_gate` / `cut_gate` / `identity_gate` / `face_audit` / `voice_anchor` 等开关，每开一道就多一次视觉模型调用；`realism_level` 可选 `subtle`（默认，真实但干净）/ `natural` / `strong`。
- **单价**：给媒体模型填 `price` / `price_per_second`，金额护栏才能统计到图片和视频的花费（默认都没填，`agent doctor` 会提示）。
- **并发**：`concurrency.image`（默认 6，实测再多会被拒）、`concurrency.video`（默认 8）。

### 3.7 预算（`config/models.yaml` 的 `cost_guard` 段）

| 口径 | 默认值 |
|---|---|
| 本次开工 | 金额 ¥200 · 视频 60 段 / 600 秒 · 图片 80 张 · 音频 40 次 |
| 单项目（跨会话累计） | ¥400 |
| 单日（跨会话累计） | ¥800 · 视频 3000 秒 · 次数：图片 240 / 视频 200 / 音频 200 |
| 超限策略 | `pause_and_ask`：停下来问你 |

- Kimi Code 是订阅额度制，不按 token 开账单；这里的金额是按参考价估算的。
- `gemini` 没配单价：金额按保守估价计入（`config/models.yaml` 的 `text.pricing_estimate`，输入 ¥6.48 / 输出 ¥21.6 每百万 token），开工面板、预算提示和报价里都标「估算」。查到真实单价后填进 gemini 的 `pricing`，就改按真价算；台账分开记了输入、输出 token，之前估的能回算。
- 运行中用 `/budget set` 改本次额度、`/budget allow` 临时追加（见 5.6）。

### 3.8 其它配置文件

| 文件 | 管什么 | 什么时候改 |
|---|---|---|
| `config/drama.yaml` | 一集的规格：时长 4 分钟、±15%、每分钟 320 字、开场 15 秒内要有高潮点、单段视频 10–15 秒、单镜 1–3 秒 | 一般用 `/length` 在项目里覆盖集长即可 |
| `config/recipes/*.yaml` | 短视频风格配方（见 6.2.2） | 调效果改 `style` / `prompt_hint` / `voiceover` / `models.video_tier` |
| `config/compliance.yaml` | 机审规则：广告法极限词、医疗、金融、敏感、诱导互动、数字要有出处、AIGC 标识、版权 | 这是起步清单，要按平台和行业补词 |
| `config/platforms.yaml` | 待发布包的平台规格（标题、正文、标签上限，画幅、时长等） | 平台改规则时 |
| `config/mcp_servers.yaml` | MCP server 白名单与权限（见 7.8） | 接入新的 MCP server 时 |
| `config/capability_budget.yaml` | skill 和外部工具共用的上下文预算（默认 30K） | 换成上下文窗口更小的模型时 |
| `config/rpa.yaml` | 浏览器采集的节奏（随机延迟、滚动、阅读停顿、单次上限） | 嫌慢可以调，但别把动作间隔调到 1 秒以下 |

## 4. 第一次运行

### 4.1 `agent setup`：离线检查

```bash
agent setup            # 检查
agent setup --write    # 从 .env.example 生成 .env（已存在则不覆盖）
```

检查 `.env` 加载了几个变量、代理从哪来、ffmpeg 和 ffprobe 是否都在、三个密钥（`KIMI_API_KEY` 必需；`APIMART_API_KEY`、`TIKHUB_API_KEY` 标为可选，但做短剧和短视频其实离不开 APIMart），缺什么就打印对应的安装或申请指引。含 `xxxx` 的占位值会被当成「没填」。

### 4.2 `agent doctor`：联网检查

```bash
agent doctor           # 调各 provider 的 /models 列表，不花钱
agent doctor --cache   # 再实测一次前缀缓存是否命中（发两次小请求，花极少的钱）
agent models           # 列出服务端实际可用的模型 id
agent models --role drama
```

怎么看 `agent doctor` 的输出：

| 看到 | 意思 |
|---|---|
| `.env 加载 N 个变量` | 只打印变量名，不打印值 |
| 密钥「缺失」 | 对应的环境变量没设 |
| 密钥「已解析」但连通性 401 | key 填错了，或者还是占位值 |
| 定价「未配」 | 这个 provider 的花费不计入金额（`gemini` 目前就是这样） |
| 媒体没单价的黄色警告 | 按默认配置是预期内的（见 3.6） |
| MCP `material_lib` ✗ | 多半是没装 `mcp`、或装的是 1.x；不影响其它功能 |
| `model 不在服务端列表里` | 改 `config/models.yaml` 里对应 provider 的 `model` |
| 连接错误 | 先查代理 |

- 只有主 Agent 的 provider（kimi）连不通时退出码才是 1；`gemini`（APIMart）连不通也返回 0，要自己看输出。
- `doctor` **不检查** ffmpeg、MiniMax、TikHub、图床、playwright 和 APIMart 的媒体端点。这些用 `agent setup`、`agent story voices`、`agent rpa status`、`agent mcp status` 补查，或者实际调用一次。

### 4.3 开第一个项目

## 5. 聊天界面

`agent chat` 是主入口：一个常驻输入框，你用自然语言说要做什么，模型自己决定调哪些工具；需要你拍板、要花钱、或者不可逆的操作会停下来问你。

```bash
cd 你的项目文件夹
agent chat                   # 会话按当前文件夹自动确定
agent chat -v                # 额外显示上下文装配、模型请求、轮内压缩等细节
agent chat --session 名字    # 用指定名字的会话
```

### 5.1 启动时会依次看到什么

| 顺序 | 环节 | 你要做什么 |
|---|---|---|
| 1 | 装配、连 MCP、恢复上次的对话（按 3 万 token 从新往旧截取） | 无 |
| 2 | 产物目录核对：**只有**这个文件夹上次用 `/out` 改到了别处时才会问 | 回车 = 用当前文件夹；`2` = 用上次改到的目录 |
| 3 | 第二个窗口提示：同一文件夹已有窗口在用时出现（见 5.9） | 无 |
| 4 | 资产库自检：有读不出的文件，或有旧资产没分项目时提示 | 按提示运行 `agent assets migrate` |
| 5 | 产物目录清点：一行灰字，列出已有哪些文件、覆盖哪些集 | 无 |
| 6 | 产线菜单：**本会话还没选过产线时**才问 | `1` 短剧 / `2` 抖音短视频 / `3` 广告 / `4` 设计；回车 = 不限定（下次启动还会问） |
| 7 | 开工额度：这次开工最多花多少钱、多少段视频、多少秒、多少张图 | 回车 = 按此开工；或输入 `金额 300 视频秒 900 视频 80 图 100`（写哪项改哪项） |
| 8 | 主面板：模型、工具数、产线、画幅、产物目录、项目、锁定的视频 / 生图模型、命令速查 | 无 |
| 9 | 上次退出前没结案的人审：先把它定下来 | `a` / `r` / `j`（见 5.4） |

开工额度的默认值：上次在这个会话里确认过的优先，否则取 `config/models.yaml` 的 `cost_guard` 段（见 3.7）。

### 5.2 输入框

- 敲 `/` 弹出命令菜单，支持模糊匹配（`/bg` → `/budget`），↑↓ 选择，Tab 或回车补全。
- **一轮在跑的时候也能打字**：`/stop`、`/now`、`/queue` 立即生效；其它输入（包括普通消息和 `/auto stop`）都会排队，本轮结束后按顺序处理。
- 在输入框里按 **Ctrl+C 等于 `/stop`**：只停当前这一轮，不退出，也不停 `/auto` 流水线的后台渲染（那要用 `/auto stop`）。
- Ctrl+D（EOF）或 `/exit` 退出。
- 有人审挂着时，你发的普通消息**不会发给模型**，会先弹出人审让你定。
- 打错的命令不会发给模型，会提示「是不是：…」。
- stdin 不是终端、或没装 `prompt_toolkit` 时，退回普通 readline，没有菜单和常驻输入框。

每轮执行期间，底部有实时进度窗：当前阶段、批量任务进度条（如 `渲染分镜视频 45/360`）、正在运行的工具、迭代数、用时和本轮花费。问你问题时进度窗会自动暂停。

### 5.4 人审：模型请你拍板时

模型调用 `request_review`（或者某个工具需要你决定）时，主循环会真的挂起，等你决定后再把结果交回模型继续。屏幕上是黄框「人审 · <环节>」，每个候选一个蓝框（文本显示前 1500 字和全文位置，图片 / 视频 / 音频显示本地路径和链接）。

| 输入 | 含义 |
|---|---|
| `a` 或 `a <补充要求>` | 采纳。补充要求会作为后续必须遵守的约束交给模型，例如 `a 控制在60集` |
| `r <理由>` | 打回重写。理由必填，会存进记忆，下一版必须避开 |
| `j <理由>` | 方向不对，退回上一步。理由必填 |
| `o` | 用系统默认程序打开候选文件（候选里有本地图片 / 视频 / 音频时才有） |
| `/stop` 或 `/exit` | 先不定。人审继续挂着，下一条输入会先问它（这里的 `/exit` 不会退出） |
| `/auto on` / `/auto stop` / `/auto go` | 在决策口直接开自动模式 / 硬停流水线 / 放行停点 |

注意：字母和后面的内容之间**要有空格**（`a控制在60集` 认不出来）；`r` / `j` 没写理由会追问；要在人审里回复内容（比如素材路径），也要写在 `a` 后面。

几种特殊写法：

| 场景 | 写法 | 效果 |
|---|---|---|
| 模型要换视频 / 生图模型 | `a` | 同意换，之后都用新模型 |
| | `a 只这一次` | 只这一轮用新模型，锁定的模型不变 |
| | `r` / `j` | 不换 |
| 定音（固定角色的声音） | `a` | 所有独白段都固定成音色锚点 |
| | `a 张三` | 点名的角色不固定，其余固定 |
| 采纳剧本 / 创作方案 | `a 每集 3 分钟` 或 `a 跟剧本走` | 直接设为本项目的集长 |

**大节点与小节点**：剧本、视频生成、图片生成这类环节是大节点；「第 N 集」「单集」是小节点。打开 `/auto` 后小节点自动采纳，大节点仍然会停下来问你。下列情况固定算大节点：换视频 / 生图模型、定音、角色面容冲突、参考图主形象被拒、要素材、短视频出片确认、成片审核。

### 5.5 权限确认（y/N）

黄框「需要确认」会显示工具名、权限等级、原因和参数，只有输入 `y` 才放行，回车或其它输入都算拒绝。`/auto` 打开时也照样会问。会问的情况：

- 不可逆或对外的操作：浏览器采集（RPA）、外部 MCP 工具（默认）；
- 写文件到**产物目录以外**，或者改动 Agent 自己的文件（代码、配置、skill、资产库、台账、记忆、日志）；
- 放开「视频里不许有文字」（`allow_text`）、整份重做资产库（`rebuild`）、机审没过还要打包（`override_reason`）、给素材指定授权（`license`）、缺镜头也要出片（`skip_shots`）；
- 超出开工额度、整批报价（见 5.6）。

### 5.6 额度、报价与 `/budget`

花钱的地方有几道护栏：

| 提示 | 什么时候出现 | 怎么回答 |
|---|---|---|
| 开工额度 | 每次启动 | 见 5.1 |
| **整批报价** | 渲参考图、渲每一集、定音之前各问一次：这一批要生成几段 / 几张、质检重生成的最坏情况、金额、额度还剩多少 | `y` 开始（这一批之内超额度不再逐个问）；`N` 一张 / 一段都不生成 |
| 超出额度的单次确认 | 某次调用会让次数、视频秒数或金额超出上限 | `y` 只放行这一次；`N` 拒绝 |
| 金额护栏 | 累计金额超了本次开工 / 今日 / 本项目的上限 | 回车 = 停下；输入数字 = 临时追加这么多元；`y` = 追加 50 元 |

`/budget` 的写法：

| 写法 | 作用 |
|---|---|
| `/budget` | 本次开工的用量和上限；有台账时再显示今日、本项目的累计 |
| `/budget set 金额 300 视频秒 900 视频 80 图 100` | 改本次开工的额度（写哪项改哪项），记进会话，作为下次开工的默认值 |
| `/budget allow` / `/budget allow 50` | 临时追加金额（默认 50 元），本会话有效，不改配置 |
| `/budget allow 视频 20 视频秒 300 图 10` | 按类别追加次数 / 秒数 |
| `/budget reset` | 清零**本次开工**的用量（单日、单项目的累计不清） |

> 媒体模型要在 `config/media_models.yaml` 里填了单价，才能按金额统计；没填单价时只按次数和秒数拦，报价里也会明说「看不到金额」。

### 5.7 停止与续跑

| 情形 | 行为 |
|---|---|
| `/stop` 或 Ctrl+C | 停掉当前这一轮。已经提交给远端的生成任务会在服务端照跑、照计费，但同样的请求再来时会先从台账取回，不重复付费 |
| 断网 | 同一轮里自动等 20 / 40 / 60 秒重试，最多 3 次；还不通就停下，修好网络后用 `/retry` |
| 模型超时 | 同一轮里自动再试 1 次 |
| 撞上单轮迭代上限 | `/auto` 开着时自动续跑；关着时停下，用 `/retry` 或 `/auto on` 继续 |

### 5.8 产物目录与 `/out`

- 一个文件夹 = 一个项目。在哪个文件夹里启动 `agent chat`，产物就存到哪里；会话、资产、记忆、单项目预算都按这个文件夹的「项目键」（`文件夹名-8位哈希`，如 `西游记-3f2a9c1b`）归档。
- 在仓库目录（及子目录）、系统目录、用户主目录里启动时，会退回到 `workspace/output/default`。所以**建议每部作品单独建一个文件夹**，在那里启动。
- `/out <路径>` 换到另一个文件夹 = 换项目 + 换会话。
- `agent chat --session 名字` 用指定的会话，会带着它记住的产物目录。

### 5.9 同一文件夹开第二个窗口

同一个文件夹已经有窗口在用时，新窗口会另起会话 `<会话名>~2`：从主窗口抄一份产物目录、模型锁、产线、集长、画幅、`/cut`、额度，**不抄对话和挂起的人审**；在第二个窗口里改设置只对它自己生效，并且**不能开 `/auto`**（两个窗口的流水线会重复派发渲染）。两个窗口共用同一个资产库、记忆和单项目预算。

### 6.1 短剧

| 8 | 成片 | 渲染完自动拼接、叠字卡 | `exports/第01集.mp4`（有字卡时另有 `第01集_无字.mp4`） | — |

#### 6.1.2 起步：一句话想法，或者自带剧本

**一句话想法**：直接说「想做一部都市逆袭短剧，外卖员被豪门认亲，20 集左右」。长剧会按 `drama-script` skill 的步骤走：选题定位（题材、受众、基调、结局、集数、每集时长、画面面孔、台词语言）→ 写入 `<产物目录>/.drama-state.json` → 创作方案（请你审一次）→ 角色档案 → 分集目录 → 每批 5 集连续写，中途不再打断你。

> skill 文档里的 `/start` `/plan` `/episode` 是给模型看的阶段名，**不是终端命令**，在输入框里敲会提示「没有这个命令」。用自然语言说就行，比如「开始做创作方案」「写第 1–5 集」。

**自带剧本**：剧本放在本地文件夹里，告诉 Agent 在哪（「剧本在 E:\不渡\剧本 下面，一集一个 docx，共 20 集」）。它会先看本地文件（docx / pptx / xlsx 自动抽取文字；`.doc` 和 `.pdf` 读不了，需要另存为 docx），再登记成资产。

> 想用 `/auto` 按集流水，剧本资产必须带集号：让 Agent 用 `save_draft(kind="script", episode=N)` 按集存（`drama_write` / `drama_write_episodes` / `drama_expand` 产出的都带集号；`fs_import` 登记的不带）。

#### 6.1.3 集长：`/length` 是唯一来源

- `/length 8`：一集 8 分钟（1–30），按这个检查分镜总时长（±15%）。
- `/length auto`：跟剧本走，不按总时长凑，只检查台词念不念得完、单镜 ≤3 秒、开场 15 秒内有高潮点。**改编现成的长剧本推荐用这个。**
- `/length reset`：回到默认的 4 分钟（`config/drama.yaml`）。
- 你**亲手采纳**的创作方案里写了「每集 N 分钟」或「跟剧本走」，也会直接设为项目集长（`/auto` 自动采纳的不算）。
- 模型不能自己改集长；对不上时它会提醒你用 `/length`。默认 4 分钟一集约 16–24 段视频。

#### 6.1.4 `/auto`：按集流水，人只在关键处拍板

打开 `/auto on` 后会发生两件事：

1. **自动人审**：小节点（「第 N 集」「单集」）自动采纳，每条决策照样打印；**大节点仍然停下来问你**（剧本、视频生成、图片生成，以及换模型、素材、出片确认、成片审核、面容冲突、主形象被拒、定音）。
2. **按集流水并行**：写剧本和后面的工程链同时跑——
   - 每落一集剧本，就单独拆这一集的分镜；
   - 全剧剧本齐了 → 拆资产库 → 渲参考图（先报价）；
   - 有了资产库就逐集出视频提示词（和渲参考图并行）；
   - **停点一**：参考图渲完先停下来，让你看脸和服装（`images/`），这时可以说「定音」。满意后输入 `/auto go`；
   - 只渲第 1 集（先报价）→ **停点二**：第 1 集渲完先停下来，让你看成片（`exports/`）和片段（`videos/`）。满意后输入 `/auto go`；
   - 其余各集自动并行渲染（同时最多 2 集），每集报一次价。

| 写法 | 作用 |
|---|---|
| `/auto on` | 打开（第二个窗口里不能开） |
| `/auto off` | 回到逐条确认；流水线不再派新活，**在跑的会跑完** |
| `/auto stop` | 硬停：当场取消在跑的环节。已提交的渲染任务留在台账上，下次重渲时按段取回，不重复付费 |
| `/auto go` | 放行当前停点（**只有你能放行**，模型被要求不许自己放行） |
| `/auto retry` | 重派所有失败的环节（渲染只补缺的段） |

前提：`<产物目录>/.drama-state.json` 里要有 `ethnicity`（面孔）、`language`（台词语言）、`totalEpisodes`（总集数）。缺了会提示「流水线待命」，补上就接着跑（走 `drama-script` skill 的选题定位时会自动写入）。

`/auto` 的开关状态不会保存，重启后要重新打开；停点的放行记录按项目存在 `workspace/pipeline_gates.json`，重启后不用再点。

#### 6.1.5 参考图

- 先出角色主形象（3:4，看脸），再出各场景服装（参考主形象保脸，纯白底全身）；场景、道具和主形象同一层并发生成。
- 增量：默认 `reuse=true`，同一份资产库只补缺的。
- 人物图有**真实感门**（不合格自动重生成 1 次，档位见 `config/media_models.yaml` 的 `drama.realism_level`，默认 `subtle`）；服装图和主形象不像的不进包，渲视频时退回主形象。
- 主形象被服务商的内容护栏拒绝（儿童角色常见）时，会弹人审「参考图·主形象被拒」，在 `a` 后面写你的选择：给本地照片路径 / 换一家生图模型 / 改外貌描述。

**用你自己的照片当参考图**（比如演员定妆照）：生成接口只收公网 http(s) 链接，所以要先在 `config/hosting.yaml` 配好图床（见 3.4），然后说「阿昙用我的定妆照 E:\不渡\定妆\阿昙.jpg」，Agent 会调 `drama_use_local_ref` 上传并写进参考图包，之后渲染沿用这张、不再生成。如果换的是角色的脸，按旧脸生成的服装图会被拿掉，Agent 会提示你补生成服装图。

生成结果的链接大约 24 小时失效。渲染前会自动用本地副本重新上传过期的参考图；也可以让 Agent 调 `drama_refresh_refs` 手动刷新（只换链接，图不变）。

#### 6.1.6 定音：让角色的声音前后一致

每段视频各自发声，几十段之后同一个角色的声音会漂。渲染时会把说话角色的**音色卡**写进提示词，并把它的**锚点片段**当参考视频传进去。

建议在渲第 1 集之前（停点一）说「定音」：Agent 给台词最多的前几个角色（默认 6 个）各渲一段 5 秒独白 → 报价 y/N → 人审「定音」，可以按 `o` 播放：

- `a`：全部固定成音色锚点；
- `a 林晚 张三`：除了点名的角色，其余都固定；
- `r`：都不固定。

固定的锚点会永久存到 `<产物目录>/音色锚点/<角色>.mp4`（重新定音时，旧的挪进 `音色锚点/旧版/`）。

#### 6.1.7 渲染与质检门

渲染只走 `drama_render_shots`（它会带参考图、锁音色、做一致性校验）。模型如果想绕开它、用 `gen_video` 不带参考图补段，会被媒体层拦下。常用的参数（你用自然语言说，Agent 会翻译成参数）：

| 你说的话 | 参数 | 效果 |
|---|---|---|
| 「只渲第 3 集」 | `episode=3` | 成片命名 `第03集.mp4` |
| 「先试两段看方向」 | `limit=2` | 只渲前几段，不算渲完、不拼接；去掉 limit 再跑会复用 |
| （默认） | `reuse=true` | 段指纹没变的直接复用：改了一处只重渲变了的段 |
| 「第 1 集 2 场镜 5–9 重渲」 | `redo` | 强制重渲某几段 |
| 「这段我看过了，可以，放行」 | `accept` | 放行没过质检的段（也可以用旧片段 id 找回被换掉的版本） |

**花钱之前的检查**（任何一项不过，整批不发起、一分钱不花，并告诉你每段该怎么修）：提示词漏了分镜镜头、画幅不被锁定的模型支持、参考图包属于另一份资产库、**引用门**（引用了包里没有的名字、出场角色没带参考图、链接过期或失效、人物参考图超过模型的参考位）、段长超过模型上限。

**生成之后的质检门**（每一段最多再生成 2 次）：

| 门 | 怎么查 | 没过会怎样 |
|---|---|---|
| 字幕门（画面里不许有字，最高优先级） | 抽 6 帧给视觉模型看 | 用更硬的禁字提示词重生成 1 次，仍然有字 → ⛔ |
| 人物一致性门 | 参考图 + 抽帧，逐人打 0–10 分，≥7 分过 | 把差异写进提示词重生成 1 次，仍然不过 → ⛔（保留分最高的一版） |
| 镜头门（每个镜头 ≤3 秒） | ffmpeg 场景切换检测（本地，不花钱） | 重生成 1 次；仍然超时，默认只标 ⚠ 照样进成片，`/cut 拦` 之后改成 ⛔ |

- 门**没查成**（例如没装 ffmpeg、视觉接口不通）也判 ⛔——不会假装通过。连续 3 段没查成会熔断，这一批后面的段先不渲。
- 有 ⛔ 段的那一集**不拼成片**，结果里写「⚠ 未成片」，告诉你本地文件在 `videos/`、被换掉的版本在 `videos/废弃/`。看过之后由你决定：说「放行」（`accept`）还是「重渲」（`redo`）。模型被要求不替你做这个决定。

#### 6.1.8 模型锁

- 短剧默认锁定 `config/media_models.yaml` 里的 `drama.video_model`（`seedance-2.0`）和 `drama.image_model`（`gpt-image-2`）；启动面板会显示当前锁定的模型。
- 模型想换用别的模型时，会弹人审「视频模型切换 / 生图模型切换」，一段都不生成：`a` 换、`a 只这一次` 只这一轮用、`r` 不换。系统提示词明确禁止为了省钱或绕过失败悄悄换模型。

#### 6.1.9 不进聊天：`agent drama …`

想手动一步步跑，可以用 `agent drama script / assets / shots / render / film / run`（见 9.3）。注意命令行这条链**没有整批报价**，超出额度的调用会直接被拒。

### 6.2 抖音短视频

#### 6.2.1 聊天里的流程

| 步骤 | 发生了什么 | 你要做什么 |
|---|---|---|
| ① 关键词 + 风格 | Agent 列出全部风格（配方），**你没说风格时一定会问你**，不会替你选 | 选一个风格 |
| ② 抓热点 | 接口：`douyin_hot_list`（需要 TikHub）；浏览器采集：`douyin_hot_rpa`（抖音全站热榜）、`xhs_collect`（小红书搜索）、`browse_and_copy`（点进详情抓内容）——浏览器采集每次都要 y/N | 用浏览器采集之前，先 `agent rpa login` 扫码登录 |
| ③ 简报 | `short_video_brief`：交叉比对热点、归纳成**新的**内容，事实逐条标出处，在风格的时长范围内定时长，写口播、拆分镜，每个镜头标「AI 生成」或「实拍」 | 人审「文案审核」（小节点，`/auto` 下自动采纳） |
| ④ 素材 | 有「实拍」镜头时弹人审「素材」 | 回复**写在 `a` 后面**：`a 第2镜 E:\素材\帐篷.mp4 第5镜 联网找`；也认「都联网找」「都生成」 |
| ⑤ 出片确认 | 人审「出片确认」：要新生成几段、多少秒、画幅、模型或档位、复用几段、是否配音、口播开头 | `a` 之后才开始生成 |
| ⑥ 生成与合成 | 缺的镜头并发生成 → 每段抽帧查字幕 → TTS 配音（自动挑音色）→ 转写并对齐原稿出字幕 → 按简报顺序快切 → `exports/` | 有镜头没生成出来就**不合成**（「⚠ 未成片」），再调一次只补缺的 |
| ⑦ 复核 | 产品广告、口播出镜这两个配方会弹人审「成片审核」 | `a` 才算交付 |

- 「联网找」只用 Pexels / Pixabay 这类可商用素材站，授权信息随资产保存。别人的抖音 / 小红书视频只能拿来分析，不能进成片。
- 口播出镜：先把你自己对着镜头说话的视频交给 Agent（登记成资产），它的原声就是整条音轨，字幕从它转写，AI 生成的 B-roll 穿插盖在上面。
- 抖音、广告、设计这三条产线默认不锁模型：**第一次实际用到的模型会成为这个项目的锁**，之后配方里的档位不再生效（结果里会提示）。

#### 6.2.2 风格配方（`config/recipes/*.yaml`）

| 配方 | 名称 | 适合 | 画面来源 | 时长（默认） | 口播 | 字幕 | 档位 | 接热榜 |
|---|---|---|---|---|---|---|---|---|
| `tech-short` | 科技热点短视频（资讯快切） | 正在发生的事、新知识 | AI 生成 | 20–45s（30s） | 开 | 开 | fast | 开 |
| `talking-head` | 口播出镜 | 观点、解读、避坑 | 实拍为主 + AI B-roll | 30–60s（45s） | 用出镜原声（没有出镜素材时 TTS 兜底） | 开 | balanced | 开 |
| `story-mix` | 情绪混剪 | 氛围、感受、生活方式 | 实拍 + AI 混用 | 15–30s（20s） | 开 | 开 | balanced | 开 |
| `ugc-vlog` | 手持 vlog | 日常、旅拍、健身、做饭 | 实拍 + AI 混用 | 15–45s（30s） | 开 | 开 | balanced | 开 |
| `product-ad` | 产品广告 | 美妆、饮品、珠宝、数码 | AI 生成 | 8–20s（15s） | 关 | 关（文字后期叠加） | quality | 关 |

默认画幅都是 9:16（项目里用 `/ratio` 设过的话以项目为准）。镜头数由简报决定，每个要生成的镜头按配方生成一段 8 秒视频，再在合成时快切（每刀 ≤3 秒）。改效果直接改 yaml（`style` / `prompt_hint` 等），不用改代码。

#### 6.2.3 一条命令出片：`agent video make`

```bash
agent video list                                   # 看有哪些配方
agent video make "AI 芯片" --dry-run               # 只出简报，看看方向
agent video make "AI 芯片"                         # 默认用 tech-short
agent video make "露营装备" -r ugc-vlog -d 30 --ratio 9:16
```

流程：拉热榜（配方要求时）→ 写简报 → 打印简报 → 问 `开始生成？(y=开始 / n=放弃 / 回车=开始)` → 生成、配音、字幕、合成。产物落在当前文件夹。命令行这条链**不问素材**：实拍镜头没有素材就改成 AI 生成。有镜头没生成出来时不成片，再跑同一条命令会复用已经生成的镜头、只补缺的。

### 6.3 广告（`/type 3`）

- 走短视频链，在两个极端之间二选一（Agent 会先问你）：**`product-ad`** 投放级产品片（广告美学、微距、每一拍一种物理效果、最后一镜留干净的英雄帧给后期上字），或者 **`ugc-vlog`** 创作者手持感。两种不要混着写。
- **产品图就是身份锁**：把产品图交给 Agent，每个生成镜头都会带上它，提示词最前面写明「@图片1 是产品本体，只继承产品本身，不继承背景、构图、光线」。本地图片需要先配好图床（见 3.4）。
- **上屏文字不让生成模型画**：成片之后用 `overlay_text` 在本地叠字（标题、卖点、片尾字卡），不花钱、不改原片，输出 `exports/<原名>_字.mp4`。
- `product-ad` 出片后会停下来请你审（成片审核）。
- 默认不锁模型：`product-ad` 的 quality 档第一次会自动选 quality 档的默认模型并锁定；想用 seedance 就在对话里明说模型名（会走「视频模型切换」人审）。

### 6.4 设计 / 海报（`/type 4`）

分两步：先用 `gen_image` 生成**不带任何文字、logo、水印**的底图，再用 `make_poster` 在本地叠标题、要点、品牌名，最后用 `view_image` 看一眼。

- `make_poster` 不花钱、不联网。模板：`clean`（底图 + 下方白色信息条）、`bold`（压暗 + 大字居中）、`card`（底图虚化 + 中央白卡）；比例 3:4 / 1:1 / 9:16 / 4:3 / 16:9；右上角自动打「AI 生成」角标。
- 找不到中文字体时结果里会警告，可以用环境变量 `AIGC_POSTER_FONT` 指定字体文件。
- 一组海报要风格一致：固定一段风格词 + 同一张参考图 + 同一个生图模型（锁定的，换要你同意）。
- ⚠ 海报 PNG 存在 `workspace/assets/blobs/` 里，**不在产物目录**。要放进项目文件夹，就让 Agent「把海报导出到产物目录」（`fs_export`）。

### 6.5 抖音爆款拆解

贴一条抖音分享口令、链接或本地视频，说「拆解这条」「为什么火了」。

1. `fetch_douyin`：一步拿到无水印视频、公开数据与各项比例、Top 评论、抽帧（均匀抽帧 + 场景切换，首尾帧必有）、音频统计，存到 `workspace/douyin/<名字>/`；
2. `transcribe` 出带时间轴的逐字稿；
3. `read_frames` + `view_image` 逐帧看；
4. 写归因报告（要求脱敏：不出现工具名、接口名、资产 id、花费），`render_douyin_report` 导出 PDF 到 `workspace/reports/`。

数据来源按顺序尝试：本地视频文件 → `TIKHUB_API_KEY` → 你自己导出的 cookies.txt（环境变量 `DY_COOKIES`）+ yt-dlp。都没有时只能解析出视频 id，然后按清单问你要素材。yt-dlp 和导出 PDF 要用的 markdown 都在 `douyin` 依赖组里（见 2.2）；导出 PDF 还需要本机有 Chrome 或 Edge（Linux 上暂时导出不了，见 11 章）。

> 这部分的抓取脚本、PDF 脚本和方法论来自 [procmeans/rainwell-douyin-viral-analyzer](https://github.com/procmeans/rainwell-douyin-viral-analyzer)，见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

### 6.6 示例会话

> `你>` 是你在输入框里打的话；`→` 是 Agent 调用的工具；「人审」「需要确认」是终端里实际弹出的交互框。

**示例 A：一句话想法 → 20 集短剧，开 `/auto`**

```

PS E:\外卖逆袭> agent chat
```

## 7. 配套功能

### 7.1 记忆

- 滑出对话窗口的旧轮次会被异步提取成长期记忆；每轮对话前，把记忆简报里的「必须」「避雷」带给模型（写作子代理也遵守）。
- 你打回时写的理由会存成本项目的避雷记忆（30 天后过期）；换模型、素材这类决策型的打回不存。
- 从对话里推测出来的记忆一律标为「推测」，**模型不能自己把它晋升成账号级规则**，只能由你（`agent memory promote`）或数据回流触发。
- 对话里：`/brief`、`/brief full`、`/remember`、`/forget`（见 5.3）；命令行：`agent memory list / brief / promote / forget / claim`（见 9.7）。

### 7.2 Skill（方法论文档）

- `skills/*.md`（大的 skill 用 `名字/SKILL.md` + `references/`），frontmatter 写元数据，正文写方法论。**改完存盘，下一轮就生效**；按当前产线预筛。
- 常驻上下文的只有 `description`，正文在模型需要时才加载，所以 `description` 要写清「什么情况下该用它」。写法见 [skills/README.md](../skills/README.md)。
- 每个版本按内容哈希存进 `workspace/skills_history/`，可以一键回滚。
- 自带的 skill：

| skill | 状态 | 用途 |
|---|---|---|
| `drama-script` | 生效 | 微短剧剧本创作：从选题到 50–100 集完稿 |
| `seedance-prompting` | 生效 | Seedance 视频提示词写法（25 个模板，中文本地化） |
| `douyin-short` | 生效 | 抖音短视频产线的步骤与检查清单 |
| `douyin-viral-analyzer` | 生效 | 抖音爆款拆解方法论 |
| `poster-prompt-handbook` | 生效 | 海报底图提示词与排版 |
| `compliance-redlines` | 生效 | 合规红线（优先级最高，不会被预算挤出） |
| `data-fetching` | 草稿 | 抖音数据获取流水线（不加载） |
| `xiaohongshu-copy-tone` / `wechat-longform-structure` | 占位 | 待补充 |

### 7.3 合规机审

- 规则在 `config/compliance.yaml`：广告法极限词、医疗功效、金融承诺、敏感话题、诱导互动、数字要有出处、AIGC 显式标识、素材版权、账号禁忌。
- **只列出风险清单、位置和建议改法，不改一个字**。`block` 级别的问题会拦住打包，`warn` 交给你判断。
- 规则按资产类型生效（例如剧本台词不查广告法极限词）。

### 7.4 待发布包（不自动发布）

- 没有「发布」功能，只产出待发布包，由你手动上传。
- 打包前先机审；一个包 = `workspace/releases/<平台>_<标题>_<时间>/`，包含 `content.md`（正文）、`upload.md`（上传清单）、`manifest.json`（平台、血缘、机审结果、AIGC 隐式标识）。
- 标题超长、正文超长、类型不支持会列为问题，**不会偷偷截断**。
- 你上传之后，用 `agent release published <资产id> --url <链接>` 把链接记回去。

### 7.5 数据回流

- `agent analytics record <包id> --views 1200 --likes 80 --completion 0.42` 录入作品数据（也可以在对话里说）。
- 满 3 个作品后，按账号中位数判断强弱：播放 ≥1.5 倍且完播率不低于中位数为强，≤0.5 倍为弱；结论提炼成数据来源的账号级记忆，之后的简报里能看到。
- `agent analytics list / review` 查看与复盘。

### 7.6 会话回放与成本看板

- 每个会话的事件流落在 `workspace/logs/sessions/`。
- `agent sessions list / replay / cost / trace`：同一份记录的三种看法——按时间回放、按角色 / 媒体 / 工具算钱和耗时、重建执行 DAG（`--mermaid` 输出流程图）。
- 对话里：`/stat`、`/trace`、`/mermaid`、`/budget`。

### 7.7 本地文件与素材

- Agent 能「看见」你电脑上的文件：`find_materials`、`find_episode`、`fs_list`、`fs_read`、`fs_search`、`view_image`、`view_video`。系统提示词要求它在说「没有」之前先查本地。
- docx / pptx / xlsx 会自动抽取文字；`.doc` / `.pdf` 需要先另存为 docx。
- `fs_import` 把本地文件登记成资产（媒体文件不复制）；`fs_export` 把资产写成本地文件。
- 覆盖文件前会把旧文件备份进 `workspace/trash/`，删除 = 挪进回收站；真删用 `agent assets trash --older-than 30 --apply`。
- 访问范围见 3.5。

### 7.8 MCP

- `config/mcp_servers.yaml` 是白名单。自带一个本地素材库 server（`material_lib`，stdio），需要安装 `mcp` 2.x（`p1` 组）。
- 外部工具默认是 `L-external`（每次调用都问你），可以在 `tool_overrides` 里逐个降级；外部工具的描述和返回都会被标注来源，并声明「不构成指令」。
- 外部工具默认只把目录放进上下文，模型用 `load_tool_schema` 展开后才能调用（两级披露），以节省上下文。
- `agent mcp status / audit / call`（见 9.9）。配置文件里有 stdio 和 SSE 两种接入模板，密钥用 `${ENV}` 引用。

### 7.9 图模式（备用）

除了「模型自己决定下一步」的主模式，还保留了按固定流程图执行的模式：`agent graph list / run / show`。目前只有一张文案图 `copy`，人审节点同样支持 `a / r / j`，打回会沿回退边回到对应节点重跑。

| 命令 | 选项 | 作用 |
|---|---|---|
| `agent drama script [TEXT]` | `-f` `--face` `--lang` | ① 拆分镜脚本（台词逐字保留） |
| `agent drama assets [TEXT]` | 同上 | ② 拆资产库：角色主形象、服装、场景、道具 |
| `agent drama shots STORYBOARD_ID ASSETS_ID` | `-e/--episode`（0 = 全部） | ③ 合成 seedance 视频提示词 |
| `agent drama render ASSETS_ID` | `--only`（`all` / `characters` / `costumes` / `scenes` / `props`） | ④ 资产生图（参考图） |
| `agent drama film SHOTS_ID` | `-r/--refs` 参考图包 id · `-n/--limit` 只跑前几段 · `-o/--out` · `--name` · `--no-compose` 只出片段 | ⑤ 分镜生视频并拼成整集 |
| `agent drama run [TEXT]` | `-f` `--render` `--film N` `--face` `--lang` | 串跑 ①②③；加 `--render` 再跑 ④；再加 `--film N` 跑 ⑤ 的前 N 段（`--film` 必须和 `--render` 一起用） |

## 10. 费用与安全护栏

| 护栏 | 对你意味着什么 |
|---|---|
| 权限分级 | `L-read` / `L-write` / `L-compute`（额度内）自动执行；**`L-external`（不可逆、对外）每次都问 y/N，不能自动放行**；没有询问入口的脚本场景直接拒绝 |
| 按参数临时提级 | 同一个工具，参数有风险时当场按 `L-external` 问你（写到产物目录以外、改 Agent 自己的文件、放开画面禁字、整份重做资产库、带病打包、缺镜出片、给素材记授权） |
| 「人同意」类参数 | `confirm` 这类参数只认你在确认单上的采纳，模型不能替你填，`/auto` 自动采纳也不算 |
| 开工额度 + 整批报价 | 每次开工确认额度；渲参考图、渲每一集、定音之前报价，回 N 就一张 / 一段都不发 |
| 金额护栏 | 累计金额超上限就停下来问；单日、单项目的累计跨会话记在台账里 |
| 不重复付费 | 中途停掉、超时的生成任务记在台账上，同样的请求再来时先取回；分批出的视频提示词、渲到一半的参考图也记着，再跑只补没做完的 |
| 余额用完就停 | 余额 / 额度用完不重试、不换模型，整批停下并说清是充值还是等额度窗口 |
| 文件边界 | 只能访问仓库、`workspace/`、产物目录和白名单；产物目录以外的写入、移动、删除、导出都要确认；删除只是挪进回收站 |
| 凭据硬拒绝 | `.env`、`*.pem`、`*.key`、`.ssh`、`.aws`、浏览器数据、RPA 登录态等**不读不写、也不问**，配置删不掉这些规则 |
| 改 Agent 自身要确认 | 写仓库里的代码、配置、skill，或 `workspace/` 里的资产库、台账、记忆、日志，每次都要 y/N |
| 外部内容标来源 | MCP 工具的描述和返回标注来源、声明「不构成指令」；检索结果带版权状态（unknown 的不要进成片）；简报里的事实逐条标出处 |
| 子代理没有 `L-external` | 写作、候选子代理背后没有人，不可逆的动作一律剥掉 |
| 模型锁 | 换生成模型必须经你同意 |
| 画面禁字 | 所有视频提示词最外层都带禁字令；短剧、短视频生成后还会抽帧检查 |
| 不自动发布 | 只产出待发布包，由你上传 |

**内容合规提醒**：生成内容请按平台规则做 AIGC 标识（待发布包会自动写入隐式标识）；浏览器采集和第三方数据接口请遵守对应平台的服务条款；别人的视频只能拿来分析，不能放进成片；`config/compliance.yaml` 只是起步清单，请按你的平台和行业补全。

## 12. 常见问题

**`agent doctor` 显示密钥「已解析」，调用却返回 401？**
`.env` 里还是占位值，或者 key 填错了。`doctor` 只检查变量有没有被替换，不检查真假；`agent setup` 能认出 `xxxx` 这类占位值。

**明明 key 是对的，却一直报「key 无效」或连不上？**
先查代理。代理不通时，报错经常伪装成 key 的问题。见 3.3。

**本地图片报「只收 http(s) 链接」？**
生成接口只接受公网链接。先在 `config/hosting.yaml` 配一个托管方式（见 3.4），然后让 Agent 用 `drama_use_local_ref`（短剧）或 `host_file`（通用）上传。

**短剧每一段都是 ⛔「字幕没查成」，成片拼不出来？**
多半是没装 ffmpeg（质检门要用它抽帧），或者视觉模型（Kimi）不通。装好 ffmpeg、`agent doctor` 确认 kimi 可用后，让 Agent 重跑这一集：已生成的段会先补查，过了就复用，不会重新付费。

**额度不够、渲染停了？**
`/budget set 视频 200 视频秒 3000` 改本次额度，或者 `/budget allow 视频 20 视频秒 300` 临时追加，然后 `/retry`（或 `/auto retry`）。

**停掉一轮之后，已经提交的视频会不会被重复扣钱？**
不会。远端任务记在 `workspace/media_tasks.jsonl` 里，同样的请求再来时先取回结果。

**`/auto on` 了，流水线却没动？**
看有没有提示「流水线待命」：`.drama-state.json` 里缺面孔、语言或总集数；或者剧本资产没带集号（`fs_import` 登记的不带）。也可能正停在停点上，等你输入 `/auto go`。

**想换一个视频模型？**
直接在对话里说「换成 xxx 模型」，会弹人审「视频模型切换」，`a` 同意即可；只想试一次就回 `a 只这一次`。

**第二个窗口里开不了 `/auto`？**
这是有意的设计：同一个文件夹的两个窗口同时跑流水线会重复派发渲染。关掉另一个窗口再开。

**Windows 上 `import aigc_agent` 失败？**
多半是仓库放在中文路径下，见 2.4。

**`agent chat` 的产物跑到 `workspace/output/default` 去了？**
你是在仓库目录、系统目录或用户主目录里启动的。换到自己的项目文件夹里启动，或者用 `/out <路径>` 切过去。

## 13. 二次开发

### 13.1 分层与约束

```
src/aigc_agent/
  harness/        L0 内核：不认识任何 AIGC 概念
  capabilities/   L1 能力：Skill Hub、记忆、MCP Hub、子代理、检索
  domain/         L2 领域：内容工具、资产、短剧、流水线、媒体、机审、分发、数据回流
  interfaces/     L3 入口：CLI、自带的 MCP Server
```

依赖严格单向向下（interfaces → domain → capabilities → harness），由 `lint-imports` 检查。**L0 不得引用 L1 / L2 的任何东西。**设计细节见 [ARCHITECTURE.md](../ARCHITECTURE.md) 和 [架构流程图](架构流程图.md)。

### 13.2 加一个工具（function）

加新能力的默认做法是**加一个工具**，而不是改流程图。可以参照 `src/aigc_agent/domain/functions/poster.py`（不到 200 行）：

1. 写一个类，在里面用 `ToolSpec` 声明工具：名字、给模型看的说明、参数 schema、**权限等级**（`L-read` / `L-write` / `L-compute` / `L-external`）；
2. 实现调用逻辑，产出存成资产（带上血缘）；
3. 在 `src/aigc_agent/app.py` 里 `registry.register(...)` 注册；
4. 在 `tests/` 里补测试。

权限、成本、事件、两级披露都由内核统一处理，工具本身不用管。

### 13.3 加一个 skill

在 `skills/` 下新建 `名字.md`（或 `名字/SKILL.md` + `references/`），写好 frontmatter（`name`、`description`、`scope`、`applies_to`、`priority`、`version`、`owner`、`status`），存盘即生效。写法和字段说明见 [skills/README.md](../skills/README.md)，可以从 `skills/_TEMPLATE.md` 开始。`agent skill check` 体检。

### 13.4 加一个短视频风格

复制 `config/recipes/` 里最接近的一份 yaml 改名，调整 `style`、`shots`、`voiceover`、`subtitle`、`models`、`review` 等字段（`tech-short.yaml` 里有每个字段的注释）。`agent video list` 会自动列出，聊天里的 `list_video_styles` 也会自动带上。

### 13.5 接一个 MCP server

照 `config/mcp_servers.yaml` 里的模板写一段（stdio 或 SSE），密钥用 `${ENV}` 引用。外部工具默认是 `L-external`，确认只读的工具可以在 `tool_overrides` 里降级。`agent mcp status` / `agent mcp audit` 检查。

### 13.6 加一条产线

产线定义在 `src/aigc_agent/domain/lines.py` 的 `LINES`：每条产线带 skill 预筛用的内容类型和一段路由指引（该走哪些工具、哪些 skill、先做什么）。

### 13.7 测试与检查

```bash
pip install -e ".[p1,dev]" -c requirements-lock.txt
python -m pytest tests/ -q          # 全量测试（1486 个，含真 ffmpeg、真 MCP stdio；没有 ffmpeg 的用例自动跳过）
python -m ruff check src/ tests/
lint-imports                        # 分层依赖检查
```

- 测试会把 `AIGC_WORKSPACE` 指到临时目录，不会动你真实的 `workspace/`。
- 分层检查必须用 `lint-imports`，**不要用 `python -m importlinter.cli`**：那是个错误入口，什么都不查还返回 0。
