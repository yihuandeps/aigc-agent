# 海报 / 封面 / 图文卡片手册

## 一句话原则

**字不让生图模型画，字本地叠。** 生图模型写中文十有八九错字、变形，改一个字就得整张重生成；
`make_poster` 在本地把标题、要点、品牌名叠到底图上，改字免费、字体统一、右上角自动打 AIGC 角标
（平台要求画面显式标识，别等上传前再补）。

所以一张海报永远是两步：

1. `gen_image` 出一张**不带任何文字、不带 logo、不带水印**的底图，并给文字留出位置
2. `make_poster` 叠字（模板 `clean` / `bold` / `card`），`view_image` 看一眼再交给用户

## 什么时候用

- 短剧 / 短视频的封面、每集海报、分集卡片
- 产品海报、活动海报、小红书图文的封面与内页
- 用户说"配张图""出个封面""做张海报"——哪怕他没说"设计"

## 比例与用途

| 用途 | 比例 | 尺寸 | 模板建议 |
|------|------|------|----------|
| 抖音 / 视频号封面、竖版海报 | 9:16 | 1080×1920 | bold |
| 小红书封面、短剧海报 | 3:4 | 1080×1440 | clean / bold |
| 朋友圈、方图 | 1:1 | 1080×1080 | clean |
| 横版海报、公众号头图 | 16:9 / 4:3 | 1920×1080 / 1440×1080 | clean |

`gen_image` 的 `aspect_ratio` 和 `make_poster` 的 `aspect_ratio` **要一致**，底图比例不对时
make_poster 会等比放大后居中裁切——不变形，但会裁掉边缘，所以主体别贴边。

## 底图 prompt 的结构（按块写，别跳）

1. **主体**：是什么、在做什么、占画面几分之几（"人物占右半，左侧留空"）
2. **构图与留白**：文字要落在哪，就让那块干净——上方 1/3 留空 / 下方 1/3 纯色或虚化
3. **光线**：一种主光 + 方向（侧光、逆光轮廓光、黄金时刻），不写"高质量"这种废话
4. **材质与色调**：两三个词定调（暖调胶片感 / 冷调金属感 / 奶油色柔和）
5. **风格锁定**：一段固定的风格词，多张图**原样复用**（见下）
6. **负向**：no text, no letters, no logo, no watermark, no caption；人物类再加 no extra fingers

产品类海报的"广告美学词"直接借 `seedance-prompting` 的 `03-商业与产品`：premium /
luxury advertising aesthetic、体积光、浅景深、单一主体居中——它们对静态图同样有效。

## 风格锁定（多张要一致时）

- **同一段风格词**：把色调、光线、材质、镜头感写成一段，每张 prompt 末尾原样贴，不改一个字
- **同一张参考图**：`gen_image` 的 `image` 参数带上第一张成功的底图，正文里 @图片1 点名
  "只继承色调、光线和构图气质，不继承主体和文字"
- **同一个生图模型**：换模型 = 换画风；本会话锁定的生图模型别自己换（要换会问用户）
- 人物要一致：参考图必须是那个人的主形象（短剧走 drama_render_assets 的参考图包）

## 文字区预留

- 封面标题 ≤ 14 字，副标题 ≤ 2 行；`card` 模板的正文（subtitle）用换行分条，每条一句
- 底图 prompt 里写明留白位置：`clean` 模板文字在**下方**，`bold` 在**居中**，`card` 铺**中央白卡**
  （底图会被虚化当背景，所以 card 的底图只要色调对就行）
- 品牌名 / 账号名走 `brand` 参数，别写进 prompt

## 检查清单

- [ ] 底图上没有任何文字、logo、水印（有就重出底图，不要试图叠字盖住）
- [ ] 文字落在留白区，没压在脸上、没压在产品上
- [ ] 标题字数够短，`title_lines` ≤ 2（3 行就该改标题）
- [ ] 多张之间色调一致（并排 `view_image` 看）
- [ ] AIGC 角标在（除非用户明确说这张不需要）
- [ ] 真人肖像：只用用户自己提供或本项目生成的角色，不用真实公众人物

## 禁止

- 不生成真实公众人物、明星、政治人物的肖像；不模仿在世艺术家的署名风格
- 不把品牌 logo 交给生图模型画（几乎必错且有侵权风险），需要就后期贴矢量
- 不用生图模型出带中文的图当成品
- 未成年人形象只做非写实 / 远景，不做写实面部特写（服务商也会拒）
