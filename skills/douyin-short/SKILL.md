# 抖音短视频分支

一条视频的路径是固定的，**每一步都有对应的工具，不要跳步、不要自己脑补热点**：

```
① 确认风格 → ② RPA 抓热点 → ③ 归纳成新内容（简报）→ ④ 补实拍素材 → ⑤ 出片 → ⑥ 看片复核
```

## ① 确认风格（先问，再动手）

- 调 `list_video_styles`，把风格列给用户选：资讯快切 / 口播出镜 / 情绪混剪 / 手持vlog / 产品广告。
  手持vlog 和 产品广告 是两个极端（相机缺陷换真实感 vs 投放级广告光），**别混着写**；写它们的镜头前可拉 `seedance-prompting` 对应参考看要点与坑。
- 用户没明确说风格就**必须问一次**，不要替他选 —— 风格决定时长范围、画面靠生成还是实拍、要不要口播。
- 用户已经说了（"做条口播的"）就直接对应，不再问。

## ② 抓热点（RPA，真实数据）

按顺序调，能调几个调几个，结果的资产 id 都留着给 ③：

1. `douyin_hot_rpa` —— 抖音热榜（浏览器抓）
2. `xhs_collect(keyword=关键词)` —— 小红书搜索结果
3. 想看细节再 `browse_and_copy(site="xhs", keyword=关键词, count=5)` —— 真点进去抓详情与热评
4. RPA 不可用（没装 playwright / 没登录）就退回 `douyin_hot_list`（接口），并**告诉用户是接口数据**

这些工具是 L-external，会弹确认 —— 那是设计，它们用的是用户自己的登录态。
一条都没抓到就停下来说清楚，不要凭印象编"热点"。

## ③ 归纳成新内容

- `short_video_brief(keyword, style, sources=[上面所有资产 id], notes=用户额外要求)`。
- 模型会交叉比对热点、归纳成一段**新的内容**（不是复述某一条），事实逐条标出处，
  并在风格允许范围内按内容密度定时长、写口播、拆分镜、标每个镜头是 AI 生成还是要实拍。
- 把简报贴给用户看一眼（标题、角度、时长与理由、口播、分镜、需要的素材），
  这是唯一一次策划层面的确认；用户改要求就带 notes 重跑。

## ④ 补实拍/外部素材（两条路，用户定的）

简报里有 source=real 的镜头时：

1. `request_materials(brief_id)` —— 挂起，向用户列出每个镜头要什么、可搜的关键词。
   用户三种答法：给文件路径 / "联网找" / "改生成"。
2. 用户回复后原话交给 `resolve_materials(brief_id, reply)`：
   - 文件路径 → 自动登记成素材并绑到镜头（图片也行，会做成静止镜头）
   - "生成" → 该镜头改为 AI 生成
   - "联网找" → 返回搜索词，接着 `stock_media_search(query=英文词, kind=video)` 挑一条、
     `fetch_stock_media(handle)` 下载，拿到资产 id
3. 联网只用 **Pexels / Pixabay** 这类明确可商用的素材站。别人的抖音/小红书视频只能分析，不能进成片。
   用户自己给的链接才用 `fetch_media_url`，授权记 unknown 并提醒他确认。
4. 没配素材站 key 时如实说明（.env 加 PEXELS_API_KEY / PIXABAY_API_KEY），改问用户要或改生成。

## ⑤ 出片

- `short_video_produce(brief_id, materials={"3": "as_xxx"})`：缺的镜头并发生成（网络失败自动重试，
  重跑复用已生成的），配音（音色按文案自动挑）、字幕（转写时间轴 + 原稿回贴）、按风格快切合成。
- 没提供素材的实拍镜头会改用 AI 生成并在结果里标出来 —— 转告用户。
- 出片很慢很贵：撞上预算护栏停下来问人是刹车不是故障。

## ⑥ 看片复核

- `view_video(source=成片资产id, question="有没有字幕/文字、变脸、穿帮？口播和画面对得上吗？")`
- 有问题按镜头修：单个镜头重生成就把它从素材/复用里去掉再 `short_video_produce`；文案问题回 ③ 带 notes 重跑。
- 简报里的 risks（事实存疑 / 合规 / 版权）要原样转告用户，不要吞掉。

## 检查清单

- [ ] 风格是用户确认的，不是我替他选的
- [ ] 热点来自真实抓取（RPA 或接口），来源资产 id 进了简报
- [ ] 简报里每条依据有出处，数字没有编
- [ ] 需要实拍的镜头都走过 request_materials，联网素材只来自可商用站
- [ ] 出片后用 view_video 看过，风险提示转告了用户
