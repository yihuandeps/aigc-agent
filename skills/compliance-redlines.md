# 合规红线

> priority 100：不参与能力预算降级，永不被挤出。机审规则的**机器版**在
> `config/compliance.yaml`（`check_compliance` 照它执行）；这里是给模型看的判断方法。
> 两边要一起改：词表改 yaml，判断原则改这里。

## 什么时候用

任何内容进入审核 / 打包环节前，无条件加载。发布是不可逆动作，事后撤回代价远高于事前多看一眼。

## 核心方法

先跑 `check_compliance` 拿机审清单，再按下面四条做人判断能做、机器做不了的部分：

1. **极限词与承诺**：机审报 block 的词一个都不能留。替换原则是「可验证的具体描述」：
   「最好的」→「实测 30 天没掉线」；「稳赚」→ 删掉并加风险提示。
2. **数字必须有出处**：只能用热榜、财报、官方通报里真实存在的数值，句内注明来源。
   拿不准就改成定性描述。**编一个听起来很顺的数字比没有数字更糟**。
3. **AIGC 标识两件套**：显式（正文开头或结尾一句「本内容由 AI 生成」，视频/图片加角标或在简介注明）
   + 隐式（发布包 manifest 已写入，上传时平台有勾选项的要勾）。缺显式标识机审直接 block。
4. **素材版权**：`search_library` 里版权状态为 unknown 的素材不得进成片；自产（generated）或人给的（human）才用。

## 检查清单

- [ ] 机审报告里 block 为 0（warn 逐条看过并决定）
- [ ] 正文没有极限词、疗效承诺、收益承诺
- [ ] 每个数字都能指出来源
- [ ] 显式 AIGC 标识在正文里；视频/图片有角标或简介说明
- [ ] 所用素材版权状态不是 unknown
- [ ] 不触碰账号层禁忌（Memory Brief 的避雷区）
- [ ] 敏感话题（政治、宗教、民族、灾难、疾病）已由人判断措辞是否稳妥

## 反例

- 「全网第一的降噪耳机，100% 无感佩戴」—— 三个极限词，一个都不能留。
- 「今年销量涨了 300%」—— 数字没有出处；改成「据 X 财报，Q2 销量同比增长 300%」或改成定性。
- AI 写的种草文直接发，正文没提 AI —— 违反标识办法，机审 block。
- 从素材库拿了一段「海边日落」进成片，版权状态 unknown —— 换成自产素材或确认授权。

## 禁止事项

- 不得为了过机审把极限词改成谐音、拆字、加符号（「笫一」「最_好」）—— 平台按语义判，这是掩耳盗铃。
- 不得删掉 AIGC 标识换取「更自然」。
- 不得用 override_reason 绕过 block 级问题，除非法务书面确认并把理由写清楚。
